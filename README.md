# DWG-Field

Open AutoCAD DWG and DXF drawings on Android, iPhone and the web. Files are read on the device and never uploaded.

One web codebase (`web/app.html` + `web/engine.js`) runs everywhere:
- **Phone**: Capacitor projects in `android/` and `ios/`, set up so DWG and DXF files show DWG-Field under "Open with" and "Share"
- **Web**: `www/` also works as an installable, offline web app

## Features
Opens DWG (AutoCAD R13 through 2018+, via LibreDWG compiled to WebAssembly) and DXF (ASCII and binary) ·
pinch to zoom, drag to pan, double-tap to zoom in, Fit · layer panel with on/off switches, search, all on/off ·
blocks (nested, arrays, mirrored), dimensions, hatches (solid and pattern), text and multiline text, arcs, ellipses,
splines, polylines with bulges, 3D faces and polyface meshes drawn flat · dark or paper background, drawing colors or
black and white · drawing info (units, size, extents, what was left out).

Not yet: paper-space layouts, linetypes (dashed lines draw solid), lineweights, images/xrefs, 3D solids, multileaders.

## Layout
| Path | What it is |
| --- | --- |
| `web/engine.js` | Turns parsed DWG/DXF data into a display list (Path2D per layer and color, text runs) and draws it |
| `web/app.html` | The app UI: opening files, gestures, layers, display options, info |
| `web/build.mjs` | Builds `www/` (offline app), `dist/preview.html` (single file, libraries from CDNs) and `dist/artifact.html` |
| `samples/` | Test drawings; `samples/src/make_floorplan.py` regenerates the built-in sample (needs `ezdxf`) |
| `tools/test-viewer.mjs` | Opens every sample at phone size in Chromium and fails if one doesn't render |
| `android/`, `ios/` | Native phone projects (generated by Capacitor, then customised for opening CAD files) |
| `.github/workflows/build.yml` | Runs the test, builds the Android APK (and a rolling "latest" release) and compiles iOS |

## Commands
```sh
npm install                 # once
npm test                    # build and run the viewer test (screenshots in test-output/)
npm run serve               # try it in a browser at http://localhost:8080

npm run android             # sync and open in Android Studio
npm run ios                 # sync and open in Xcode (Mac only)
```

## Installing the Android test build
Every push to `main` publishes `DWG-Field.apk` under the **latest** release. Open that page on the phone, download
the APK, and allow your browser to install apps when Android asks. Test builds share one debug key in
`android/app/dwgviewer-debug.keystore`, so each new build installs over the last; a Play Store release needs its
own private upload key.

## iPhone
`ios/` builds in Xcode on a Mac. Running it on a phone needs an Apple developer account for signing
(free accounts can install to your own phone for 7 days; TestFlight and the App Store need the paid program).
