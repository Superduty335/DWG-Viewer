# DWG-Field

Open AutoCAD DWG and DXF drawings on Android, iPhone and the web. Files are read on the device and never uploaded.

One web codebase (`web/app.html` + `web/engine.js`) runs everywhere:
- **Phone**: Capacitor projects in `android/` and `ios/`, set up so DWG and DXF files show DWG-Field under "Open with" and "Share"
- **Web**: `www/` also works as an installable, offline web app

## Features
Opens DWG (AutoCAD R13 through 2018+, via LibreDWG compiled to WebAssembly) and DXF (ASCII and binary) ·
pinch to zoom, drag to pan, double-tap to zoom in, Fit · layer panel with on/off switches, search, all on/off ·
blocks (nested, arrays, mirrored), dimensions, hatches (solid and pattern), text and multiline text, arcs, ellipses,
splines, polylines with bulges, 3D faces and polyface meshes drawn flat · dark or paper background, drawing colors or
black and white · drawing info (units, size, extents, what was left out).

Not yet: paper-space layouts, linetypes (dashed lines draw solid), lineweights, images/xrefs, 3D solids, multileaders.

## DWG-Field Plus
A second app built from the same code: everything in the viewer, plus field points and light drafting.
It installs alongside DWG-Field (app id `com.superduty335.dwgfield.plus`).

- **Points**: tap to add numbered points with a description and optional elevation, or type northing/easting.
  Edit, renumber, zoom to or delete them from the point list.
- **Drafting**: line (chains until Done), polyline (Done or Close), circle (center, then a point or a typed radius),
  text, erase (your own objects only), undo/redo. Lines and polylines can take a typed distance and angle.
- **Object snap**: endpoint, midpoint, center, intersection, node and nearest, on the drawing and on what you add.
  Snaps skip layers that are switched off. Tap to place; press and drag to aim with a crosshair and magnifier above
  your finger. With a mouse, click to place and drag to pan; F3 toggles snap.
- **Export**: points as CSV (P,N,E,Z,D or P,E,N,Z,D, no header row) and everything you added as an AutoCAD R12 DXF
  in the drawing's coordinates (layers `FIELD-POINTS`, `FIELD-POINT-LABELS`, `FIELD-DRAFT`), so it lines up when
  inserted at 0,0 or attached as an xref. On a phone, export opens the share sheet (save to Files/Drive, email…).
- Your work is saved on the device with each drawing and comes back when you reopen it.

Plus is `web/plus.js` + `web/plus.css` on top of the viewer. The build inlines them into `www-plus/` and copies its
page to `android/app/src/plus/assets/public/`; the Android `plus` product flavor supplies that page, the app name
and the badged icon (`npm run icons` re-renders it via `tools/make-plus-icons.mjs`). iOS builds only the viewer for now.

## Layout
| Path | What it is |
| --- | --- |
| `web/engine.js` | Turns parsed DWG/DXF data into a display list (Path2D per layer and color, text runs) and draws it |
| `web/app.html` | The app UI: opening files, gestures, layers, display options, info |
| `web/plus.js`, `web/plus.css` | DWG-Field Plus: points, drafting tools, object snap, CSV/DXF export |
| `web/build.mjs` | Builds `www/` and `www-plus/` (offline apps), plus single-file previews of each in `dist/` |
| `samples/` | Test drawings; `samples/src/make_floorplan.py` regenerates the built-in sample (needs `ezdxf`) |
| `tools/test-viewer.mjs` | Opens every sample at phone size in Chromium and fails if one doesn't render |
| `tools/test-plus.mjs` | Drives Plus at phone and desktop size: snaps, every drafting tool, undo, export, saving |
| `android/`, `ios/` | Native phone projects (generated by Capacitor, then customised for opening CAD files) |
| `.github/workflows/build.yml` | Runs the tests, builds both Android APKs (and a rolling "latest" release) and compiles iOS |

## Commands
```sh
npm install                 # once
npm test                    # build and run the viewer and Plus tests (screenshots in test-output/)
npm run serve               # try it in a browser at http://localhost:8080
npm run serve:plus          # try Plus at http://localhost:8081

npm run android             # sync and open in Android Studio (pick viewerDebug or plusDebug under Build Variants)
npm run ios                 # sync and open in Xcode (Mac only)
```

## Installing the Android test build
Every push to `main` publishes `DWG-Field.apk` and `DWG-Field-Plus.apk` under the **latest** release. Open that page
on the phone, download the APK, and allow your browser to install apps when Android asks. Test builds share one debug key in
`android/app/dwgviewer-debug.keystore`, so each new build installs over the last; a Play Store release needs its
own private upload key.

## iPhone
`ios/` builds in Xcode on a Mac. Running it on a phone needs an Apple developer account for signing
(free accounts can install to your own phone for 7 days; TestFlight and the App Store need the paid program).
